# 真实轮指验证：待完成，不作为当前功能通过证据

当前已验证：合成已知起音的检测、固定增益不变性、异常间隔触发、选区和失效条件、定位试听、离线运行。尚未验证：真实琵琶起音检测准确度、教师认可的练习建议、噪声与混响下的可靠性。

## 素材与标注

取得使用许可的真实持续同音轮指录音，覆盖至少 3 位演奏者、慢 / 中 / 快三种速度、均匀与有意不均匀的片段；另加入安静 / 有混响 / 自动增益的对照。每段 5～10 秒。避免将姓名等个人信息放入素材文件名。

由有教学经验的琵琶演奏者标注实际起音时间及值得复听的片段。建议 CSV 字段：`clip_id,onset_seconds,review_start_seconds,review_end_seconds,teacher_note`。教师评审时先听原始录音，不先看工具标记，避免提示偏差。

## 检查方式

- 检测匹配：预先固定 ±25 ms 容差，一对一匹配人工起音，分别报告 precision、recall、时间误差及各速度 / 录音条件，不只报告平均值。
- 标记价值：教师盲评标记片段是否确有可听变化，记录漏标和误标，不把“触发阈值”当作教学错误。
- 干扰控制：同一录音固定增益变化应保持相对统计稳定；速度变化单独报告，自动增益、混响和噪声用于检查失败模式。
- 阈值调整：调参片段与最终检查片段分开，防止用同一录音调整又证明效果。未经验证不输出评分或具体手指归因。

先记录基线结果，再依据失败样本改检测器；在这些工作完成前保持“待试听线索 / 真实效果待验证”的文案。
