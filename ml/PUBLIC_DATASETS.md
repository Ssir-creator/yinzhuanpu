# 可用于琵琶转谱研究的公开数据

检索日期：2026-11-01。这里区分“能训练”和“能计算转谱准确率”；只有乐器类别标签的数据不能直接当作音符级真值。

## 优先采用

| 数据源 | 琵琶内容 | 标注 | 许可与获取 | 计划用途 |
|---|---|---|---|---|
| [PipaSoundClassifier Dataset](https://github.com/ZehuiWU2009/PipaSoundClassifierDataset) | 5段作者自录琵琶，约40 MB，含弹挑、轮指、扫弦、长音和舞台演奏 | 只有 `pipa` 类别，无音高/起止时间 | 明确声明全部音频可公开使用，CC BY 4.0；Git LFS | PESTO 自监督域适配的首选公开训练集；使用时署名 “PipaSound Dataset (Zehui Wu)” |
| [ChMusic](https://github.com/HaoranWeiUTD/ChMusic) | 11种民族乐器，每种5首独奏；琵琶共5首，每首约25～280秒，44.1 kHz 双声道 | 乐器和曲目标签，无逐音标注 | 仓库为 MIT；音频从 README 提供的百度网盘或 Google Drive 下载 | 自监督训练；完整曲目级留出，选少量片段人工校正为测试集。正式再分发前再次核对音频授权说明 |

## 仅作为补充或对照

| 数据源 | 价值 | 限制 |
|---|---|---|
| [Pipa AMT Evaluation](https://github.com/Arreb-01/pipa-amt-evaluation) | 包含94.3秒《火把节之夜》琵琶音频、曲谱图片、Basic Pitch/pYIN等输出和后处理代码 | 没有人工 MIDI 真值；仓库虽为 MIT，但未单独说明原录音表演权，不能作为主要训练数据或准确率真值 |
| [MedleyDB](https://github.com/marl/medleydb) | 有旋律/音高标注和中国音乐条目，可验证评估流程 | 中国条目是二胡、笛子等，不包含琵琶；音频许可和注释代码许可需分别遵守 |
| [CCOM-HuQin](https://doi.org/10.5281/zenodo.6957454) | 专业演奏者的中国民族拉弦乐器多模态数据 | 胡琴类，不是琵琶，不应混称琵琶训练数据 |

## 第一轮实验方案

1. 下载 PipaSoundClassifier 的 `pipa/` 目录和 ChMusic 的5首琵琶曲。
2. 每个原始录音作为独立 session，保留来源、许可证、SHA-256 和署名信息。
3. 以完整录音为单位划分：训练曲目、验证曲目和测试曲目不能相互切片混用。
4. 用未标注训练曲目做 PESTO 自监督域适配。
5. 从完全留出的公开曲目中人工校正至少2～5分钟音符真值，计算 Note F1；规模不足时明确称为 pilot study。
6. 对比当前浏览器算法、原始 PESTO、域适配 PESTO和域适配加琵琶后处理。

## 可以和不可以声称的内容

可以写：

> 本项目使用公开授权的真实琵琶录音对 PESTO 进行自监督域适配，并在按曲目隔离、人工校正的测试片段上进行评估。

在没有完成标注和实验前，不可以写“准确率显著提升”“解决轮指转谱”或“构建了自有数据集”。使用公开数据训练不等于自建数据集。
